# Warung Klontong Online (Next.js)

Project ini berisi website warung klontong dengan fitur:
- Katalog produk
- Login member (demo auth)
- Checkout + payment (simulasi)

## Jalankan di lokal

```bash
npm install
npm run dev
```

Buka `http://localhost:3000`.

## Demo kredensial login

- Email: `user@warung.id`
- Password: `123456`

## Catatan

Fitur payment menggunakan API simulasi (`/api/checkout`) agar project bisa langsung dipakai tanpa integrasi gateway pihak ketiga.

# Deploy ke Vercel

Project ini siap deploy sebagai static site.

## Langkah cepat
1. Login ke Vercel CLI
   ```bash
   npx vercel login
   ```
2. Deploy production
   ```bash
   npx vercel --prod --yes
   ```
3. Saat diminta project name, isi: `na2nghermawan`
4. Setelah deploy sukses, buka dashboard Vercel lalu atur domain/project URL.

> Catatan: URL bawaan Vercel biasanya berbentuk `nama-project.vercel.app` (bukan `vircel.app`).
